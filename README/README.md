# VerifyAI

AI-Powered Application & Document Verification System

## Project Goal

VerifyAI is a full-stack system that assists organisations in
checking application forms and supporting documents.

## Technology

- React + TypeScript
- FastAPI + Python
- PostgreSQL
- OpenCV
- OCR
- Machine Learning

## Development Roadmap

1. Product Foundation
2. Document Validation
3. Document Quality AI
4. OCR & Document Understanding
5. Cross-Document Verification
6. Machine Learning
7. Human Review
8. AI Explanation & Feedback
9. Production & Deployment
